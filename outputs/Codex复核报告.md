# Codex 独立复核与修复

日期：2026-11-09。对象：WorkBuddy 回传的本地完整项目。

结论：在原交付基础上发现并修复额外缺陷，软件测试和固件构建通过，可以进入接线与上板验收。**当前没有真实串口/ADC 测量结果，不是硬件验收完成。**

## 实际发现与修复

| 问题及触发条件 | 修复 |
| --- | --- |
| Windows 管道默认 GBK 时，最终验证器把子进程输出按 UTF-8 错解码，最后打印报 UnicodeEncodeError | 统一父子进程 UTF-8；批处理复用最终验证器并传递退出码，不再用括号内过时的 ERRORLEVEL 或缺少测试时视为成功 |
| 上升沿模式先收到直流帧：单次直接冻结，却没有可显示的触发波形 | 未触发帧不消耗单次；真实设备单次无触发后重新请求，暂停可取消 |
| 保持上一条触发曲线时，统计值和 CSV 却已切换成后续未触发帧 | 显示波形、统计、导出保持同一帧 |
| 真实 SINGLE 命令的 ACK 前仍在途的旧帧被当成新单次结果 | 匹配 ACK 前保持；收到成功响应和 SINGLE 状态后才接纳结果；失败/超时不伪装成功 |
| START/STOP 发送后立即当作已执行 | 核对 SEQ/status/run_state；过期响应忽略；超时保持显示暂停，并注明设备状态未知 |
| 模拟数据断线后，CSV 根据当前模式改标为“真实设备” | 来源作为帧的元信息保存，导出和历史标签沿用原来源 |
| 模拟模式仍接纳旧串口线程排队信号 | 切换前停止线程，串口帧/断线/统计信号增加模式检查；连接新设备清理旧显示和待确认项 |
| 不匹配 SEQ 的采样率 ACK 取消新的切换请求，并提前改写当前采样率 | 先匹配请求再处理回读；过期 ACK 不取消当前请求 |
| 参考电压请求超时后输入框仍显示未生效值 | 恢复设备当前参考电压；失败/等待提示不再被刷新标签覆盖 |
| CRC 正确但采样率为 0、参考电压为 0 的帧进入显示，造成空时间轴/错误电压 | 丢弃非法采样元信息；同时拒绝非法响应参数 |
| 固件在采集中处理 START，随后 SINGLE 收尾无条件把状态改回 IDLE；也可能先 ACK SINGLE 再发此前的帧 | 命令解析延迟到完整帧处理完后的边界执行；采集/发送期间 RX 中断继续入 FIFO |
| Rx_Shift 注释仍将链接溢出归因于 memmove | 去掉未成立的归因；保留已查明的嵌套 CRC 宏膨胀说明 |

改动主要位于 `desktop/main_window.py`、`desktop/protocol.py`、`firmware/User/main.c`、`firmware/Hardware/Serial_Protocol.c`、验证与打包脚本。新测试为 `desktop/tests/test_ui_regressions.py`。未改电协笔试参考工程，未烧录。

## 关键核对和保留限制

- 阅读了 TIM3 TRGO、ADC1、DMA1_Channel1 的配置及单缓冲生命周期。当前采用“帧采满后停止硬件—显示/发送—重新采样”，发送期间不会主动启动下一帧。100kS/s 是时钟配置目标，仍需测实际采样时序。
- 阅读 CRC_BIT1 逐步循环与编译期 CRC_STEP，数值语义一致；Rx_Shift 的左移方向能处理源/目标重叠。原三方核对证据仍然是固定向量、源码常量解析和 ARMCC 编译期断言，**不是实际 C 编码器运行与 Python 解码器之间的双向运行测试**。
- 固件命令调度修正目前通过源码审查与完整构建；没有在真实 MCU 上执行验证，不能把 83 项电脑测试当作固件时序测试。
- OLED 仍用设备参考电压整数换算，电脑 CSV 记录该帧的参考电压；输入校准、精度、模拟带宽、真实 USB-TTL、DMA 中断延迟、长时间运行和数据源切换的真实驱动行为均待上板实测。
- 原 `outputs/验证报告.md`、固件说明的旧数字保留为 WorkBuddy 历史记录，顶部已标明当前版本入口；本报告为本轮新结论。未操作 WorkBuddy，也未核验其团队收件箱或声称再次调用了协作 agent。

## 接下来怎样使用

1. 双击 `outputs/启动仪器.bat`，先用模拟数据试用。
2. 按 `docs/接线与硬件.md` 确认板子、OLED、电位器、USB-TTL 电平和接线。
3. 在 Keil 中打开 `firmware/Project.uvprojx`，确认下载器配置，由用户烧录；再按 `docs/上板验收.md` 验证真实电压和波形。
4. 第一版 PA0 只接已知在 0～3.3V 内的信号；首次使用电位器。自检时不能让电位器与 PA8 同时驱动 PA0。
